# Постоянные правила проекта «Тихий дом»

## 1. Репозиторий

Вся разработка ведётся исключительно в https://github.com/vitaminoviy/po-tipy-hozy.git.
Не создавать отдельные проекты без прямого указания пользователя.

## 2. Журнал ошибок

При обнаружении ошибки обновлять `docs/ERROR_LOG.md`: дата, описание, установленная
причина, исправление, результат проверки и предотвращение повторения. Если причина
не установлена, писать об этом прямо. Нерешённые проблемы отмечать отдельно и не удалять.

## 3. Изолированный браузер

Автоматические браузерные проверки выполнять отдельным Chromium через Playwright
(по умолчанию headless) либо собственным изолированным браузером Codex. Не использовать
основной Google Chrome пользователя, его профиль, cookies, историю, пароли и вкладки.
Не открывать, не закрывать и не изменять личные браузеры и их настройки автоматически.
Не использовать системные команды открытия браузера при тестировании.
Исключение — прямое разрешение пользователя или ручной запуск им `Запустить игру.bat`.
BAT проверять только с `--no-browser`; отсутствие изолированного браузера не разрешает
заменять его личным Chrome. Сообщать об ограничении.

## 4. Предпросмотр после разработки

После каждого задания по возможности запускать актуальную игру, проверять доступность
сервера, предоставлять встроенный предпросмотр Codex и кликабельную локальную ссылку.
По возможности оставлять сервер работающим для ручной проверки. Если предпросмотр
недоступен или поставлен в очередь, честно сообщать статус; не называть его работающим
без подтверждения. Не создавать собственный интерфейс предпросмотра внутри игры.
Для запуска из Codex использовать `node scripts/launch-game.mjs --no-browser`.

## 5. Не усложнять проект без необходимости

Разрабатывать игру постепенно. Не добавлять механики без соответствующего задания,
не менять управление без разрешения и не делать редизайн без отдельного задания.
Сохранять работающие игровые функции. После успешных проверок отправлять изменения
в `main` исходного репозитория; не использовать `git push --force`.
