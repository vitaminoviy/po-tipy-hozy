# Botanical menu layers — 2026-10-25

The existing approved workshop composition is retained. Blender was not used.
Original public/images/workshop-menu.png remains unchanged.

Sources:

- workshop-cleanplate.png: image_gen edit of the original, removed overhead vines
  and foliage on the left roof slope; restored shelves, sky and roof underneath.
- workshop-ivy-draft.png: initial generated botanical source, retained for editing.
- workshop-ivy-alpha.png: isolated plant with real alpha (transparent pixels contain
  colored RGB, which some image viewers misleadingly show as a hazy backdrop).

Generation instructions: preserve composition, miniature house position, evening
window, warm lamp/candles and dark menu space; remove overhead hanging branches
and only left roof-slope ivy; restore the surfaces behind them. No text or new props.
Plant prompt: one realistic trailing ivy branch, delicate stem, alternating olive
heart-shaped leaves with veins, amber lower-right rim light, cool dusk fill;
transparent background without pot, ground, shadows or haze. The isolation pass
explicitly removed background RGB visibility through alpha while preserving leaves.

Runtime files are WebP encodings, 227434 + 224660 bytes (452094 total), generated by
`node scripts/menu/prepare-assets.mjs`. Source PNGs are not requested by the menu.
No extra dependencies. Shared vine texture is reused by six independently phased
SVG image layers. Their attachment transforms are editable in src/MainMenu.tsx;
CSS drives a twelve-second loop. Four overhead branches and two roof-edge branches
move; other plants remain in the illustration. This is not a fully simulated room.

`node scripts/menu/record-menu.mjs` records the actual isolated Chromium menu to
artifacts/menu/layered-menu.webm, screenshots and frame timings. Requires local
server 5173. No personal browser profile is used. Records over a full 12-second loop.
